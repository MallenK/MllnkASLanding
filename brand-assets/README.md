# Brand assets (sin usar en el sitio)

Archivos originales de marca bajo el naming "Academia Software":

- `logo/` — logotipo minimalista.
- `thumbnail/` — portada de Facebook.
- `instagram/` — post de presentación.

La marca activa en la landing es **Mallen'k Academy Software** (ver
`src/lib/constants.ts`), así que estos archivos **no están conectados** a
ningún componente ni a las imágenes Open Graph/favicon generadas en
`src/app/` — están aquí solo como respaldo en el repositorio. Si en algún
momento "Academia Software" pasa a ser el nombre público, estos son los
archivos de partida.
